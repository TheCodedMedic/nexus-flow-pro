How it works

  1. Open a Google Flow project tab.
  2. Optional: add character references, click Upload to project, then Hard refresh. Every prompt attaches them. Everything you add is kept in the Library: click an image there to swap it in or out. Only images new to a project need uploading.
  3. Paste your prompts, one per line. Start a line with [00.15] to name the file by timestamp.
  4. Click Start. Up to 8 prompts generate at once, 1 second apart, and each image is saved when it finishes, to your computer or a Google Drive folder.
